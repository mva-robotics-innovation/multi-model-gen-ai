Problem Statement (PS-02)

Factory workers struggle with 100+ page SOPs, hazardous process manuals, MVA Robotics X200 errors, motor bearing failures. Language barrier, no expert when needed, PPE non-compliance, phone distraction, fatigue leads to accidents. Need multimodal GenAI that reads manuals, watches expert videos, sees via camera, speaks in regional language. Plus need smartwatch SOS + emergency monitoring workstation for real accidents.

Existing Gap: No real-time system that combines Camera + Mic + Face + PPE + Voice + RAG + Smartwatch SOS + Siren + Incident Register in one market-ready product suite.

Our Solution - DUAL PRODUCT v6.0 + v7.1
