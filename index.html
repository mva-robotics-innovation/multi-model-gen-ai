Problem Statement (PS-02)

Factory workers struggle with 100+ page SOPs, hazardous process manuals, MVA Robotics X200 errors, motor bearing failures. Language barrier (Hindi/Marathi/Tamil), no expert when needed, PPE non-compliance, phone distraction, fatigue leads to accidents. Need multimodal GenAI that reads manuals, watches expert videos, sees via camera, speaks in regional language.

Existing Gap: No real-time system that combines Camera + Mic + Face + PPE + Voice + RAG in one market-ready product. Need separate modes: Student attentive system (expression deduction, distracted or attentive, mobile phone detection) + Factory monitoring mode (all workers monitoring through face detection with dotted lines) + PPE mode (safety wearing or not like helmet, gloves, shoes etc) + Home page button missing.

Our Solution - INDUX-OS Trinity Pro v6.0 FINAL

ALL MODELS + VOICE + KB

RAG over 5 manuals (245 pages), 8 expert videos, 500 logs, answers in Hindi/Marathi/Tamil/EN/ES/JA with auto voice. NEW: Home page with 4 cards to select mode, mode indicator, separate left panels for each mode.

Technology Use

Frontend

HTML/CSS/JS, MediaPipe ObjectDetector (COCO-SSD), Web Speech API (STT/TTS) with waveform canvas, Canvas IR overlay + Dotted Rect drawing setLineDash, Face-API.js TinyFaceDetector + Landmarks + Expression + AgeGender, Color detection via hidden canvas pixel analysis (yellow helmet, orange vest)

Backend

FastAPI Python 3.14 compatible, RAG logic, regex multilingual detection (hi-IN, ta-IN, ja-JP, es-ES), FormData /api/ask?mode=, FileResponse for index.html

AI Models

YOLOv8n (PPE), CHV PPE 2135 images, Roboflow PPE 1200, Hardhat Safety 5000, 94.2% hardhat detection, Custom thermal heuristic, Face-API.js 68 landmarks + 7 expressions + age/gender

Deployment

Vercel (industrial-genai.vercel.app + multi-model-gen-ai.vercel.app), GitHub mva-robotics-innovation/multi-model-gen-ai, Uvicorn, CORS, vercel.json routes, HTTPS required for camera, works on any laptop

Architecture

Flow: Camera/Mic -> Frontend (MediaPipe PPE + COCO-SSD Person+Phone + Face-API Age/Emotion/Gender + Landmarks + Color Detection Yellow Helmet Orange Vest + Web Speech STT waveform) -> FastAPI /api/ask?mode= -> RAG Search (MANUALS 102p, 45p, 38p, 32p, 28p + VIDEOS transcript) -> Mode Logic: - student: Expression deduction + Attentive (eye contact nose position) + Phone = Distracted Focus 15% + Dotted face landmarks 68 points cyan - factory: Dotted cyan boxes monitoring every worker setLineDash[6,4] + Face ID + Total count + CCTV style - ppe: Helmet yellow >800px + Vest orange >1000px + Gloves + Shoes + Goggles + Compliance 20% each + Missing list + Hindi voice - all: Combined + IR thermal -> Answer + Sources -> TTS auto speak in same language (hi-IN/marathi/ta-IN) + Compliance log + PDF report + Mode indicator + Alert banner Files: index.html (home - this page with PS-02 details), multi-modal-gen-ai.html (app with 4 separate modes + HOME overlay + dotted drawing), app.py (API), requirements.txt, vercel.json
